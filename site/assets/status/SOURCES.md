# Legacy status icon

`legacy.png` is the same UI icon used by League Skin Version, downloaded on 2026-09-28 from [CommunityDragon's client UI archive](https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-collections/global/default/images/skins-viewer/icon-legacy.png). It is bundled locally and is not covered by the project's MIT license. Copyright remains with Riot Games.

This reuse is limited to presentation. A skin receives this marker only when its Wild Rift Wiki availability is explicitly `Legacy`; no PC skin classifications, IDs, or release records are imported. The marker is not assigned to every CN `Limited` grade or every skin unavailable in the shop.

Cards, the detail caption, and the Legacy filter use the same image. A missing card image falls back to the full `LEGACY` label; details and filters keep their text if the icon fails. Card accessible names include Legacy status independently of the decorative image.
