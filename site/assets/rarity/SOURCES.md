# Wild Rift skin grade icons

These five small game UI images are bundled so grade markers work without a third-party image request. They remain game artwork and are not covered by the project's MIT license.

Skin classifications continue to use the existing Chinese official catalog, whose `qualityIcon` field maps the five quality values to client asset names. Bundled image files were retrieved from the Wild Rift-specific Wiki file records on 2026-09-27. The names in the UI remain the Chinese catalog's classifications; the Wiki's English asset names do not change a skin's grade or region.
